ScarletPhoneme 1.3  —  音素裁切音库管理器
素材 → 强制对齐 → 切点校对 → モーラ切片 → 拼接
单窗口：上面选音库，下面三个大标签，切点校对和音库索引直接显示在窗口里。
============================================================

【启动】
  双击 ScarletPhoneme.exe。不用命令行，不开网页，也不弹小窗。

【窗口结构】
  顶部   ● ScarletPhoneme   音库 [下拉]   ＋新建音库   检查环境  帮助
  标签   [切点校对]  [音库索引]  [音库管理]     ← 前两个是主功能，选中时整块变绯红
  底部   一行状态（"已保存 ×××"）+ 「日志」按钮（要看细节才点开）

  标签之间切换不会丢东西：切点校对里改了没保存，切标签/换音库会先问你要不要存。

【切点校对】（第一个标签）
  左：曲目列表（点一行就切过去，人数多的音库里也能一眼看到谁没分析）
  右上：循环（开关：开了只反复放当前选中的音）/ 吸附（开关）
  中上：▶播放  ⟲句首  上一句  下一句   时间
  中下：保存 Ctrl+S   保存并下一首 →
  下：波形（灰=峰值，绯红=RMS 响度；上方时间刻度；底部小块=每个音）
  右：当前音（音/母音/句号/起点/终点/时长/置信/峰值/落差/标记）+ 切点表

  看波形    整体看是"音块"，放大后能看到峰值细节；缩小视图时切点显示为上下小刻度
  定位      左键点波形 = 播放头移到那里，并自动选中播放头所在的音（双击 = 从那里放）
            波形本体上怎么点/拖都只是移动播放头，绝不会拖到切点、也不会动显示范围
  改切点    只有底部音名带里、两个音之间那条竖线附近才能抓住；
            缩得很小时竖线很密，抓取范围会自动收窄 —— 点空白处就是定位，
            压到线上才是拖线。想精细拖就先滚轮放大。
            也可以把播放头放好后按「起点←播放头」/「终点←播放头」
  吸附      开（默认）= 拖一条线左右两个音一起动，音与音紧贴
            关 = 只动一侧，两个音之间可以留空隙（拖音的左线=改起点，右线=改终点）
            按钮点亮＝开（红色），熄灭＝关；靠颜色区分，不带小圆点
  整体偏移  切点表可 Ctrl/Shift 多选；「偏移 −10ms / +10ms」按当前选择整体平移。
            勾上「全部音一起偏移」= 整首所有音一起动（识别整体偏一点时用）
  缩放      滚轮（以鼠标为中心）· Shift+滚轮 平移
            点波形/点音名条/拖切点都不会改变显示范围（只有滚轮、滑块、切点表、循环按钮会）
  平移      波形下方滑块：拖它左右移动，右边显示当前范围/全长
            整首显示时按一下滑块 = 以鼠标位置为中心放大
  定位      在切点表点一行 = 播放头直接放到这个音的起点，视图把这个音摆在正中间
            （方向键上下选也一样）
  播放      空格 = 从「当前播放头/选中的音」那个位置开始，一直放到本句结尾
            暂停后再按 = 从暂停的位置继续（不跳句首、不跳句尾）
            循环 = 开着的时候只反复放选中的那个音，从当前浮标位置起播
                  改切点后循环长度立刻跟着变，不用重新点这个音
  布局      左边「曲目」和右边「当前音」之间的竖条可以左右拖动，把宽度让给中间波形
  暂停      空格/「暂停」后按「继续」从原位置接着放（不会跳回句首或句尾）
  撤销      Ctrl+Z（每次拖边界前自动记一笔）
  保存      Ctrl+S → 写回 marks\*.csv + labels\*.txt（Audacity 可直接读）
            切换曲目时若没保存：是=存完切换 / 否=放弃修改 / 取消=留下
            「保存并下一首 →」= 存完跳到下一首
  换曲      左边曲目列表点一行 / PageUp / PageDown
            再点一次当前曲目 = 回到整首视图
  置信度    红 <0.30，橙 0.30–0.60，绿 ≥0.60；切点表「标记」列写「低信」等

【音库索引】（第二个标签）
  左：母音/音 列表（右侧数字 = 候选条数），上方可输入筛选
  右上：大号显示当前音 + 「152 条候选 · 干净 104 条」，按钮 刷新/■停止/循环/▶试听
  右中：候选表（来源 / 起点 / 终点 / 时长 / 置信 / 位置 / 标记），双击或空格试听
  右下：波形预览 —— 红框就是这条候选切出来的范围，点波形可从那一点试听，
        播放头（红色三角）会跟着走；右边写「view 24.40–24.84s」
  筛选：「只看可疑（有标记）」「只看句头」
  校对里保存后，索引会自动重读 marks，不用手动刷新

【音库管理】（第三个标签）
  上：音库名 / 路径 / [复制进音库|引用原位置] / 曲目数·已分析·音数·可疑·时长·占用·更新时间
  中：导入素材 / 重新分析 / 重建索引 / 导出切片 / 拼接成歌 / 打开文件夹 / 删除音库
  下：曲目表（文件 / 长度 / 状态 / 置信 / 音数 / 原文）—— 双击一行直接跳到切点校对

【导入素材 / 更新】
  1) 音频：选文件夹（可勾「包含子文件夹」）或多选 wav；原文：选一个 txt（可留空）
  2) 「预览匹配」先对账：突き合わせ成功 / 原文が見つからない音声 / 音声が見つからない原文
  3) 「开始导入」。重名选「跳过」或「覆盖」；再导同一个文件夹 = 更新素材

  原文两种写法（UTF-8 / UTF-8-BOM / CP932 / UTF-16 都认）：
     A) 文件名<TAB>原文            一行一本（推荐）
     B) 文件名 ⏎ 原文              两行一本
  文件名带不带 .wav 都行；原文里完全没写文件名时，按音频文件名排序一一对应。

【分析（CTC 强制对齐）】
  需要本机 Python + torch / transformers / numpy：
      pip install torch transformers numpy
  「は」の読み分け: 助詞の「は」は「わ」として扱う（私は → わたしわ、
  こんにちは → こんにちわ）。品詞で判断したうえで、実際の音が h か w かを
  モデルの事後確率で確かめる。判定をやり直した音は切点表の「标记」に
  「听わ」「听は」と出るので、そこだけ耳で確認すればいい。
  「重新分析」默认只算未分析；选「全部重算」会覆盖已校对过的切点。
  换电脑：装好 Python 和上面三个包即可；也可在 settings.json 的 "python" 写死路径。

【快捷键】
  空格 播放/暂停 · Ctrl+S 保存 · Ctrl+Z 撤销 · PageUp/PageDown 换曲 · Ctrl+L 日志
  （在输入框里打字时不会被这些快捷键打断）

【目录】
  ScarletPhoneme.exe    入口
  app\                  程序本体（worker.py 要靠外部 Python 跑分析，别删）
  libraries\<音库名>\    一个音库一个文件夹，可整体拷走/备份
  models\               声学模型（361MB，各音库共用）
  logs\                 运行日志
  settings.json         上次打开的音库、外部 Python 路径

  音库内部：library.json（唯一真源）· audio\ · transcript.txt ·
            marks\ labels\ · project.json · clips\ clips_all\ · render\ · plan\

【出问题】
  分析报「缺少依赖」   右上「检查环境」，按提示装包
  没声音               音量/设备可能被别的程序占用；状态栏会写「播放失败」
  搬动过源文件夹       用「引用」模式的音库会断链，重新导入该文件夹即可
  想看细节             Ctrl+L 或右下「日志」
