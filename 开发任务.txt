【切点校对 · 单音为中心】
[x] 1. 循环单音
      把「循环本句」换成「循环本音」：点亮后只反复播放当前选中的那个音
      （按切点范围播，前后留很小余量），不要带句尾停顾。
      修改中换了音，循环自动跟到新音上。

[x] 2. 「聚焦本音」改成开关
      打开后：选中哪个音，视图就自动对到那个音（切点表、波形、曲目切换都算）；
      关掉后恢复手动缩放。按钮要有亮/灭状态。

[x] 3. 删掉「整首」按钮
      想看整首：在左边曲目列表里再点一次当前曲目 = 回到整首视图。

[x] 4. 多选 / 整体偏移
      切点表支持多选（Ctrl 点、Shift 范围选）。
      加「偏移 −」「偏移 +」按钮 + 「全部」勾选框：
        勾上 = 整首所有音一起平移；不勾 = 只平移选中的音。
      用途：识别整体差一点点时，一刀全对齐。默认步长 10ms。
      平移要夹在 0..时长 内，且不能把音压成 0 长。

[x] 5. 切点表用来定位
      在切点表里点某一行 → 播放头跳到这个音的起点，视图（开了聚焦就放大）跟过去，
      波形上高亮这个音。

[x] 6. 未保存也能换曲
      切换曲目时弹「保存 / 放弃修改 / 取消」：
        保存 → 存完切换；放弃 → 直接切换；取消 → 留在当前曲目。

[x] 7. 去掉「滚轮缩放 · Shift+滚轮平移」这行提示
      多余，而且挡原文。

[x] 8. 切点联动开关（允许音之间留空隙）
      默认联动：拖一条边界，左右两个音一起动（贴着）。
      关掉联动后：只动一侧，可以在两个音之间留空隙/重叠。
        拖某个音的左边线 = 改它的起点；拖右边线 = 改它的终点。
      「起点←播放头 / 终点←播放头」在关掉联动时也只改当前音，不动邻居。

        现在：波形本体点击 = 播放头移过去 + 选中该处的音；

[x] 16. 播放中/暂停中点击切点表，浮标也要立刻跳到该音起点
        原因：暂停时定时器仍在回报位置、播放中更是一直把浮标拖回播放位置。
        修法：点表先停掉播放；暂停期间不再由定时器移动浮标。
        程序内部的同步选中不再触发定位，避免拖切点时视图乱跳。
